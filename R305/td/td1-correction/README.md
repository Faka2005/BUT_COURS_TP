# Contenu du dépôt

Dans le dossier `src`, on trouver deux modules :
  - `hello-server` : code du serveur
  - `hello-client` : code du client

Pour construire un exécutable : 

```bash
cd src/hello-server
go build
```

Ensuite, il suffit de lancer les exécutables, d'abors le serveur puis le client.
